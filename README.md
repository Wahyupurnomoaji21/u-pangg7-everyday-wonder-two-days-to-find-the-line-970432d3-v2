## About

Entry v2 for the make.fun bounty **Everyday Wonder, Two Days to Find the Line**
(`u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3`).

The program (`main.ts`, Node 22, no dependencies) writes one sentence to
`/output/entry.txt`.

## The entry

> "The bus I always miss waited at my stop this morning, doors open, as if it had finally decided to be late for me instead."

121 characters, one sentence.

## Why this angle is strong

Version 1 lost on a shadow — an angle every reader has already met a dozen
times. This version starts from a different small defeat everyone knows:
missing the same bus every morning. The wonder arrives when the pattern
breaks — the bus is still there, doors open — and the closing clause flips
the whole relationship: for once, the bus is late for *me* instead of the
other way round.

The surprise lands in a single read, it is grounded in a real and specific
moment (my stop, this morning, doors open), and every word is doing work:
no filler, no worn phrase, no borrowed image.
